# demo-react

El mismo módulo Clientes en React 19 con `@seventeen-training/react`. Tiene su **propia**
copia del contenido en `public/training/` (`appId: demo-crm-react`): ninguna app depende del
contenido de otra.

```bash
pnpm --filter demo-react dev
```

Abre http://localhost:5174. Ejecuta antes `pnpm build` en la raíz: la demo usa los paquetes compilados.
